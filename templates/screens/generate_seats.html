Pattern Descriptions
Regular Layout

All seats are of normal type with the same price. This creates a uniform layout suitable for standard theaters.

Stadium Layout

Front rows are normal, middle rows are premium, and back rows are VIP. This mimics stadium seating with better views for premium/VIP seats.

Mixed Layout

Center seats are premium/VIP while side seats are normal. This provides better viewing experience for center seats.
