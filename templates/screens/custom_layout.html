Layout Instructions
Format:
ROW:TYPE_PATTERN
Seat Type Codes:
  • N - Normal Seat
  • P - Premium Seat
  • V - VIP Seat
Example:
A:NNNNNNNNNN
B:NNNNNNNNNN
C:NNPPPPNNNN
D:NNPPPPNNNN
E:VVVVVVVVVV
F:VVVVVVVVVV
Rules:
  • Each line represents one row
  • Row letters (A, B, C...) must match screen dimensions
  • Type pattern length should match screen columns
  • Only N, P, V characters are valid
  • This will replace all existing seats
